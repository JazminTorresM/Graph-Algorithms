## 🌱 Los algoritmos


| | Algoritmo | Para qué sirve |
|:-:|---|---|
| 🍵 | **Dijkstra** | Camino más corto desde un nodo, con pesos no negativos |
| 🌿 | **Warshall-Floyd** | Caminos más cortos entre *todos* los pares de nodos |
| 🫧 | **Bellman-Ford** | Camino más corto desde un nodo; aguanta pesos negativos y detecta ciclos negativos |
| ⭐ | **A\*** | Camino más corto guiado por una heurística |
